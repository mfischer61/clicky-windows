# Course notes

Drop one Markdown file per course here, e.g. `ECE2035.md`. It appears in the
mini bar's course picker, and the selected file is sent with every question
(cloud models only, unless `CLICKY_NOTES_LOCAL=1`). Files are re-read on each
question, so edits apply immediately.

Notes files are git-ignored (only this README is tracked) so personal class
material stays local.
